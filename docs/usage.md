# Using Overdrive

## Start with the team

An administrator creates business units and users in Settings. Each user can belong to several units. Administrators see all records; other users see deals in their units and contacts explicitly linked to those deals. Sharing an organization does not reveal its unrelated contacts. Everyone who can access a commercial record can edit it; changes are versioned and audited.

## Pipeline

Create a deal with a title, value, owner, organization and optional source. A deal belongs to one business unit. An administrator can leave an initial lead unassigned; only admins see those deals until assigned.

The stages are New Lead → Briefing Ready → Proposal Ready → Proposal Sent → Negotiation → Contract. Drag a card between columns, or open its menu and use **Move to**. **Edit deal** opens the contextual editor. On the deal page, stage buttons offer another way to move it.

**Won** and **Lost** are outcomes separate from the stage. Use the visible cockpit actions to close a deal, optionally record a loss reason, or reopen it later. Archive finished or irrelevant records from the card menu or details. Archived deals can be restored.

## Work on a deal

Click a value with a pencil to edit it in place, then Save or Cancel. Larger edits and new records use a side panel. **Deal so far** is the living Markdown summary: context, current position, decisions and next steps. It can be maintained by people or an external agent. Put dated observations in notes; automatic field changes remain in the history.

Tasks always belong to a deal. Assign an owner and due date, and mark one as the primary next step. The board shows its date; hover or focus it for task context. Overdue or missing next steps are red, today's are highlighted, and future tasks are neutral. **My tasks** groups work assigned to you.

## People and organizations

Open a profile to see its accessible related deals. Edit contact details directly in the profile or list. These are shared records, so changes apply wherever the record is linked. Link existing contacts from a deal or create them there; unlinking does not delete the shared person.

## Files and links

Upload files or add external HTTP/HTTPS links. Markdown and PDF files can be previewed. Mark obsolete material **outdated**; new uploads never silently supersede previous material. Deleting a file removes its stored bytes; the audit entry remains. Deleting a link does not affect the destination website.

## Analytics

Filter by current business unit/source and deal creation dates. Conversion counts observed advancement to a later stage; Contract conversion counts observed wins. Time per stage is the median of completed active visits with a known start. Reentries are separate visits. Imported records may have incomplete history; missing durations are excluded instead of estimated. Win rate is won / (won + lost), not won / all deals.

## Keyboard

- **⌘/Ctrl K:** search and commands.
- **G, D:** pipeline; **G, T:** your tasks.
- **N:** new deal on the board.
- **⌘/Ctrl Enter:** save the focused form.
- **Escape:** close an editor or menu; unsaved editor changes prompt before discarding.
- **?:** shortcut reference.
